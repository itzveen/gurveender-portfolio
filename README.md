# Gurveender Jeet Kaur — Portfolio (PM × QA)

A modern, high-performance portfolio website engineered for **Gurveender Jeet Kaur** (Software Engineering @ Universitas Gadjah Mada), bridging **Product Management**, **Quality Assurance**, and **Full-Stack Engineering**.


---

## ⚡ Core Features & Highlights

1. **Interactive Role Lens (Perspective Switcher)**:
   - `✨ All / Synergy`: Unified view showcasing the full spectrum of PM discovery + QA edge cases.
   - `🎯 PM View`: Filters and spotlights PRD, BRD, MVP definition, C4/UML models, and agile sprint tracking.
   - `🛡️ QA View`: Spotlights test design, Playwright Page Object Model (POM), Swagger API collections in Postman, and defect metrics.
   - `💻 Full-Stack`: Highlights programming stacks (Kotlin, Python, Laravel, React Native) and academic mentorship as Teaching Assistant.

2. **Dual-Lens Project Showcase**:
   - **Tentang Dental**: Dental Clinic Mobile App (PM scope & UAT Plan + Mobile test automation collaboration).
   - **SIMATKUL**: Course Scheduling System (QA Lead, 43 Manual & 58 API Test cases, Playwright POM, Google Sheets QA Dashboard).
   - **Panenin UGM**: Agri-Marketplace (PM discovery, PRD, backlog grooming in Notion/Jira).
   - **AIS UGM**: Academic Information System (PM squad lead of 3, BRD, MVP, C4 Architecture & UML).
   - **Full-Stack & Teaching Practicum**: Teaching Assistant at UGM for Kotlin & Python + full-stack repos.

3. **4-Stage Hybrid Methodology (Amin Hamzah Inspired)**:
   - *01 Discovery & PRD* ➔ *02 Edge-Case & C4 Architecture* ➔ *03 Deep Validation (API/DB/Automation)* ➔ *04 UAT Sign-Off & Telemetry*.

4. **Live Test Suite & Edge-Case Validator**:
   - Interactive terminal simulator demonstrating passing test cases across SIMATKUL and Tentang Dental.

5. **Direct Artifact Anchors**:
   - Distinguishes **Google Drive & Notion** (for PRD, SRS, BRD, UAT sheets) and **GitHub** (for test suites and source code).

## 🚀 Running Locally

```bash
# Navigate to the project directory
cd /Users/gurveenderjeetkaur/.gemini/antigravity/scratch/qa-pm-portfolio

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Build for Production / Deployment

```bash
# Build optimized static bundle
npm run build

# Preview production build locally
npm run preview
```
